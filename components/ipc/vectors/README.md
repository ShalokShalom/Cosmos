# Wire vectors

The frozen Scale actor wire subset.

- `scale_actor.capnp` is the schema.
- `<name>.txt` is the Cap'n Proto text form.
- `<name>.bin` is the framed reference bytes, generated by `capnp encode`.
- `truncated.bin`, `bad-root.bin`, `bad-operation.bin`, `bad-body-kind.bin`,
  `missing-text.bin`, `text-no-nul.bin`, `text-out-of-bounds.bin`, and
  `multi-segment.bin` are negative vectors.

With `capnp` in `PATH`, regenerate the reference bytes:

```sh
./components/ipc/vectors/regenerate.sh
```

Check the two-way interop:

```sh
./components/ipc/vectors/check.sh
```

The scripts report a clear error when `capnp` is missing; use the reference
tool at version 1.5.0 or another conforming implementation.

The check re-encodes every text vector and compares it to the checked-in bytes,
then decodes the Elixir encoder's bytes with the reference `capnp`. The F# suite
decodes the same `.bin` files. The compatibility claim applies only to this
subset.
